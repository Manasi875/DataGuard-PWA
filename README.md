## 🔐 Admin Portal

DataGuard includes a dedicated Admin Portal for managing users, datasets, and platform activity.

### Admin Login

For the default development/demo setup:

| Field | Value |
|---|---|
| Username | `admin` |
| Email | `admin@dataguard.local` |
| Password | `Admin@12345` |
| Role | `admin` |

After logging in, the administrator can access the Admin Portal to:

- 👥 Manage users
- 🔑 Manage user roles
- 📂 View and manage datasets
- 🗑️ Delete datasets
- 📜 View activity logs
- 📊 View analysis history
- 🛡️ Monitor platform activity

### Admin Portal URL

After starting the application, open:

http://127.0.0.1:5000/admin
